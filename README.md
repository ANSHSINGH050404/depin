# depin

DePIN (decentralized physical infrastructure) experiments and tools.

## Stack

Turborepo, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/depin.git
cd depin
bun install
bun run dev   # or: bun run start
```
